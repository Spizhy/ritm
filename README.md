# РИТМ — Сайт-презентация Telegram-бота для старост и учебных групп

> У старосты много задач, не так ли? Отмены, расписание и перекличка работают сами.
> Made by **Trepet & Jutreyk & Filthness** · 30 ноября 2026

Интерактивный сайт-презентация проекта «Ритм», сверстанный на основе кастдева и документа `Ритм.md`.

## Возможности
- Интерактивный симулятор Telegram-бота и утреннего дайджеста
- Интерактивная перекличка (4 статуса: на парах / опаздываю / уважительная / отсутствую)
- Полное описание болей старост, архитектуры и дорожной карты
- Прямая ссылка на Google-форму для тестирования старостами: https://forms.gle/CSw2EMXWUU61QSm69
